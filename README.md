# Jukebox

Hi guys! This is a Minecraft-style jukebox that you can use in your browser. Open the chest, click a music disc or drag it into the jukebox and press play. There are three songs that are all handmade with code.

## Features:

A pixel art chest that you can open and close with three music discs inside.

Songs play left to right. The next one will start automatically when the previous song ends

Left click the jukebox to play or pause a song and right click it to skip the song.

Drag music discs between slots to change the order of the songs or drag them back into the chest.

Three original songs handmade with code.

## Reflection
What I learnt and what didn't work:

What didn't work: 
I thought about using Aria Math but then I found out that it is copyrighted so I couldn't put it on a public site. Thus, I decided to make my own music with code. The hardest part about this project was that since I had written so many lines of code it was hard to find the problem and fix it. I made mini typo errors like innterHTML which should be innerHTML and colol instead of color. A really sneaky bug was a typo in the middle of my code which took me some time to find.

Some things I learnt was how one small bug crashes everything after it and the browser console (F12) tells you the exact problem with the code and that was way faster than guessing.
